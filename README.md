# Sysmac 程序迁移工具包

把旧项目的 Sysmac Studio 映射程序段，按新项目的 CAD 电气图纸自动对点、改好，再一次粘贴回 Sysmac。
已在实际项目验证：粘贴成功、编译通过。

## 安装（每台电脑一次）
1. 安装 Python 3.10 以上（安装时勾选 “Add Python to PATH”）。
2. 在本文件夹打开命令行，运行：
   ```
   pip install -r requirements.txt
   ```
3. 仅支持 Windows（需要读写剪贴板）。

## 可视化工作台（推荐）
双击 **`打开工作台.bat`**，浏览器会打开工作台：
- 左边按 ①读旧程序 → ②选图纸 → ③对点并生成 → ④粘贴回 Sysmac 一步步点；
- 通用识别项目在「待判断」统一处理；「对点结果」只看结果和处理备注。原格式项目仍在「对点结果」填写判断；
- 「程序段」新旧对照，改线号/注释/新增/启用用颜色标出；
- 「图纸疑点」「待判断」「清算报告」集中看要处理的点；
- 「粘贴向导」一键复制新增变量、一键放入 Sysmac 剪贴板。

AI 助手也能操作同一个工作台（它有 JSON 接口，见 `AGENTS.md`），你在网页上看到的就是 AI 做的结果。

## 通用命名识别（试用）

双击 `打开通用识别测试工作台.bat`，使用端口 8766。工作台会分别检查旧程序和新图纸，自动选择原格式流程或通用识别流程。

- 内置识别 `I-A01-00` / `ID_A01_00`，以及 `C1_I1_0` / `C1_I01_00`、`X1_Q1_08`、`C1_1AI1I+` / `C1_1AI1` 等格式。
- 点位保留原始线号，并统一记录格式、信号类型、从站、模块、通道和模拟量端子。不同从站不因编号相似而合并。
- 通用流程目前支持文字型 PDF 中沿行排列的模块总览/接线图；扫描件、其他版式和未知命名会进入待核对，不保证任意图纸都能提取。
- 同地址且无明确冲突的映射，相似度达到 50% 即标黄保留，不要求逐条判断；同站内已移位的地址，只有未占用候选与目标唯一互选时才标黄改线号，保留原表达式。相似度不足 50%、方向相反、候选冲突、重复赋值和无法完整解析的语句才进入待判断。用户明确要求“待判断”的项继续保留。
- 支持新旧地址都存在的成组交叉错位：先按设备、侧别、动作、轴别和编号重新配对；唯一双向匹配并形成完整闭环时，标为“成组错位，标黄执行”，保留原变量、NOT/换算/联锁和目标现有硬件变量写法。每个候选须达到 80% 且领先次选及原配对至少 12 个百分点，不能只改半组。OS/DS、收回/缩回及省略工位能参与核对，编号和侧别不会被忽略。已保存的人工判断不自动覆盖；没有闭环或多候选仍待判断。
- 未对应的旧程序地址按模块合并成判断项，逐行明细仍保存在「程序有图纸无」中。
- “核对稿”仍含待判断内容，不是可用的新 PLC 程序。工作台会标出状态，并阻止写入剪贴板。只有判断和静态检查通过，才进入粘贴后编译验证。
- 通用格式的 I/O 映射按实际通道逐项核对，不采用原流程“每模块固定 16 行”的复制假设。

新命名可以在 `项目/<项目名>/命名规则.json` 中声明，示例见 `scripts/sysmac-io-check/naming_rules.example.json`。示例把图纸 `S7.DI.03.00` 与程序 `IN_S7_M3_C00` 解析为同一个点位。规则只描述地址结构，不自动推断设备功能或从站对应关系。修改规则后重新运行完整提取。

命令行入口仍为 `python scripts/sysmac-io-check/run_all.py <图纸.pdf> <旧程序目录> <输出目录>`；追加 `--reuse` 可复用同一 PDF、同一命名规则的通用识别缓存。

### 在“待判断”页面直接处理

1. 默认按问题类型分组，同类排在一起，组内按从站/模块/通道排列；各组有标题、总数及“选择整组”按钮，包含本组未显示的条目并遵从当前筛选。上方分类按钮可直接切换查看。紧凑表格默认显示 200 条，可选 100/500/全部或切换详细卡片，也可改回图纸顺序。原始问题原因与当前处理状态分别显示，保存“暂缓”不会改变分类。点“看建议 / 处理”展开原文与单项操作。
2. 大批同类项点“仅选全部筛选结果”，会选择筛选后的所有条目，不限本页；批量操作只显示这一组共同支持的方式。先点“预览选中项的批量处理”，核对范围和每行变更，再保存。单独保存不改程序；“保存并统一生成”会保存整批后只生成一次。
3. 缺少旧映射/旧备用点变成功能时，可选“按图纸新建变量”，指定现有程序段并使用变量名模板，例如 `{类型}_{工位}_{功能}`。可用字段为 `{类型}、{从站}、{模块}、{通道}、{功能}、{工位}`；默认 `{类型}_{从站}_{功能}`。预览中可逐行改名、改程序段；重名（不区分大小写）会拦截，不自动加后缀。数字量生成 BOOL，模拟量为原始 INT。确认只是叫法不同的同地址项才批量保留；重复旧赋值、侧别/方向冲突要核对实际含义。
4. 采用旧映射会保留完整表达式，支持搜索旧变量。未对应的模块可以整组保留或整组停用；停用会注释对应映射，不删除源码。排除图纸记录仅表示不用该处记录，不代表停用整台设备。
5. “暂缓”或只记备注不会消除问题。保存并重新生成后，支持的处理才真正更新程序、变量、清算和待判断名单；无效参数会显示原因并保留问题。已应用的点位可在“对点结果”行末“撤回并重算”；模块处理可在“程序有图纸无”行末撤回。旧程序、图纸或命名规则变化后需重新核对。

相邻点位看起来串位时，先点“重新生成（用已有点表）”。系统会检查整组互换；在“对点结果”筛选“成组错位，标黄执行”，查看正确变量和“说明”里的原线号→新线号，再到“变更清单/程序段”核对实际改动。不能唯一成组对应的项仍在待判断中处理。

窄窗口可以点“展开项目步骤”查看左侧流程；判断表单在主区域显示，支持整行代码查看和批量处理。原格式项目仍可从待判断页面跳到“对点结果”填写判断。

## 在不同 AI 助手里使用
本包自带给 AI 看的说明，**用哪个助手都行，把本文件夹作为工作目录打开即可**：

| 助手 | 怎么用 |
|---|---|
| Claude Code（任意项目） | 把整个文件夹复制到 `C:\Users\<你>\.claude\skills\sysmac-migrate\`，之后在任何项目里输入 `/sysmac-migrate` 或说“新项目对点” |
| Claude Code（当前文件夹） | 直接在本文件夹打开，它会读 `AGENTS.md`/`SKILL.md` |
| Codex、Cursor、Gemini CLI、Copilot 等 | 在本文件夹打开，它们会自动读 `AGENTS.md`；没有自动读的，第一句话说“先读 AGENTS.md 和 迁移原则.md” |
| 不用 AI | 按 `使用说明.md` 直接运行命令 |

## 平时怎么说（对 AI）
1. “新项目对点，项目名 XXX”，并把图纸 PDF 放进 `项目/XXX/`
2. 在 Sysmac 复制旧程序段后说 “已复制”
3. “对点并生成新程序段”
4. （可选）在报告里填判断后说 “填好了”
5. 按提示粘贴回 Sysmac、编译，有报错发截图

## 文件
- `AGENTS.md` / `SKILL.md`：给 AI 的操作说明
- `迁移原则.md`：你确认过的规则（以图纸为准、命名习惯……），**新规则也记在这里**
- `使用说明.md`：给人看的详细操作说明
- `scripts/`：全部脚本（纯 Python）
